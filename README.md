# course-notes-skill · 课件精读

> Turn an English lecture slide deck into a Chinese self-study document, delivered as PDF.
> A Claude Code / Agent Skill distilled from real-world lecture-note production.

---

## 这是什么

一个 AI skill（也提供一份纯提示词），用来把**英文课件**（PPT / 讲义 PDF）变成一份**中文可自学**的
精读文档，最终交付 PDF。

它不是为了「把 PPT 翻译一遍」，而是为了解决一个具体问题：

> **PPT 是讲课的提词卡，不是教材。**
> 老师站在讲台上会口头补三样东西——① 这个术语什么意思 ② 这一步怎么推过来的 ③ 这个工具是干嘛用的。
> PPT 上只留结论和页码。

所以精读的本质工作 = **把「老师口头会补的那部分」还原成文字**。

## 它解决哪些具体的坑

这些是从实际做讲义时读者真实卡住的地方反推出来的：

| 读者卡在哪 | 课件漏了什么 |
|---|---|
| 「怎么来的九十度」 | j 的辐角 = 90°，但这句从没写过 |
| 「为什么长度是 1/d」 | 从衍射条件推到倒格矢的那两步跳过了 |
| 「重轴是啥」 | 一个术语用了 5 次，从没定义 |
| 「这个公式原理是什么，前面没看懂」 | 图上的四个点没说在哪 |

对应的检查清单（**八查**）就写在 `SKILL.md` 里：术语 / 符号 / 系数 / 跳步 / 用途 / 约定 / 图说 / 配图。

## 安装

### 方式一：作为 Claude Code / Agent Skill

把整个目录放进 skills 目录：

```bash
# 用户级（所有项目可用）
git clone https://github.com/<your-name>/course-notes-skill.git \
  ~/.claude/skills/course-notes
```

之后在对话里说「精读这份课件」「总结第 3 讲」就会自动触发。

### 方式二：任何 AI 都能用（Claude / ChatGPT / 任意模型）

不需要 skill 机制，直接把 [`prompt/lecture-notes-prompt.zh-CN.md`](prompt/lecture-notes-prompt.zh-CN.md)
**整段复制**粘给 AI，再附上课件即可。文件里第 10 节有可填空的任务模板。

## 核心方法论速览

**八查**（每一节都过一遍）：
术语 · 符号 · 常数/系数来历 · 跳步 · 用途 · 约定 · 图说 · 配图

**分寸**（和八查同等重要）：
不是全补。判断标准只有一条——**读者会不会因为这一处卡住就读不下去？**
会 → 必补；只是「更完整 / 更漂亮」→ 不补。
机械地补会把 1 页撑成 5 页，读者会要求「简洁一点」。

**排版五条硬规矩**：
简洁（最高要求）· 矢量加粗 · 三级编号 · 色块克制 · 新术语就地定义

**最终的验收标准：读者不看 PPT，只看这份文档也能懂。**

## 适用 / 不适用

**适用**
- 大学课程课件（理工科尤佳，公式与图表多的）
- 英文授课 / 中外合办 / 外教课
- 期末复习、考前补课、课程回看

**不适用**
- 纯文字型的商业 PPT（没有推导和公式，用不上八查）
- 需要 OCR 的扫描件手写稿（本文档假设原文可提取文字或可渲染成图）
- 想要「逐字翻译」的场景（这是精读，不是翻译）

## 关于技术细节

`SKILL.md` 里附带了一个可复现的工作流（转文本 → 渲染公式页看图 → 写自包含 HTML → headless 打印 PDF），
包含实际踩过的坑（路径含中文会静默失败、`--user-data-dir` 必须每次换新目录等）。
如果你的环境不同，这部分可以整段忽略——方法论部分与工具无关。
